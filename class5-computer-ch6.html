📚 Chapter Notes
1. System Software
Definition: The main software that runs the computer hardware and helps other programs to work.
Basic → Advanced:
It starts when you turn on the PC (Booting). Without it, the computer is just a plastic box. It manages memory and processes.
🇮🇳 Daily Life: Like the Principal of a school who manages all teachers and students but doesn't teach every class.
[Image: Windows & Linux Logos managing Hardware]
💡 Tip: System = "Soul" of the computer.
Quick Check: Is Windows 10 System Software? Yes!
2. Utility Software
Definition: Software designed to help analyze, configure, optimize or maintain a computer.
Basic → Advanced:
These are the "Mechanics". They don't do your main work (like typing) but they keep the machine healthy.
🇮🇳 Daily Life: Like the Electrician or Plumber who comes to fix issues in your house.
[Image: Antivirus Shield & Broom cleaning disk]
💡 Tip: Utility = Useful Tools (Maintenance).
3. Application Software
Definition: Programs designed for end-users to perform specific tasks.
Basic → Advanced:
Apps you use for work or fun. Word for typing, Paint for drawing, Chrome for internet.
🇮🇳 Daily Life: Like your Cricket Bat or Sketchbook. You use them to do specific things.
[Image: Icons of Word, Excel, Games]
4. Open Source vs Proprietary
Open Source: Code is free for everyone to see and change (e.g., Linux, VLC).
Proprietary: Owned by a company. You must buy it and cannot change it (e.g., Windows, Photoshop).
🇮🇳 Daily Life: Open Source = Grandma's Recipe (Shared with all). Proprietary = KFC Secret Recipe (Hidden/Sold).
[Image: Unlocked Padlock vs Locked Padlock]
5. Utility Examples
  • Antivirus: Protects from viruses (QuickHeal, Norton).
  • Backup: Saves copy of data (Google Drive).
  • Compression: Reduces file size (WinZip).
  • Disk Cleanup: Deletes junk files.
[Image: WinZip and Recycle Bin icons]
6. Installation & Uninstallation
Installation: Putting a program onto the computer so it can be executed. (Setup.exe)
Uninstallation: Removing the software cleanly to free up space.
⚠️ Never just delete the folder! Use Control Panel -> Uninstall.
[Image: Progress bar installing...]
7. Importance of Updates
Updates fix bugs (errors), add new features, and patch security holes.
Why update?
To stop hackers and make the software run faster.
🇮🇳 Daily Life: Like servicing your scooter/car every 6 months to keep it running smooth.
[Image: Update Refresh Icon]
8. Version Control
Concept: Tracking changes to a file so you can recall specific versions later.
Basic Idea: Saving "File_v1", "File_v2".
Advanced: Using tools like Git to work together without overwriting each other's work.
🇮🇳 Daily Life: Video Game Checkpoints. If you die, you restart from the last save point.
[Image: Timeline showing v1.0 -> v1.1 -> v2.0]

  • Proprietary: Paid, locked code (Windows).
