Cognitive Science Lab – Session 06

Exam Strategy & Revision Cycles

Level: Basic → Expert

Duration: ~60 Minutes

Outcome: Strategy Engineering

Level 1: Basic Protocol

Lecture 6.1: The 'Read' Trap

Definition: Most aspirants read instructions passively. Top 1% read for constraints.

Psychology: Anxiety makes you rush the start. This leads to missing "NOT", "INCORRECT", or negative marking changes.

Instruction Scanning Protocol

[1. Check Time] → [2. Check Negative Marking] → [3. Check Sectional Cutoffs]

TRAP: "Select the option that is NOT incorrect." (Double Negative)

Tip: Use your finger/cursor to trace the words "NOT" or "EXCEPT".

Check 1: Instruction Awareness

Q1. If an instruction says "Select the False statement", and you select the True one because you rushed, what type of error is this?

Answer: Interpretation Error. Your brain auto-completed the task as "Find the Correct one" because that is the default mode. You must override the default.

Lecture 6.2: High-ROI Section Scanning

Concept: Never start from Question 1 unless Question 1 is easy. The exam paper is a battlefield. Capture the weak territories (easy questions) first.

The 3-Pass Strategy

Pass 1 (0-30 mins): Easy kills. 100% Sure. No calculation.

Pass 2 (30-90 mins): Moderate. Needs solving. 50-50 logic.

Pass 3 (Last 30 mins): Hard/Risky. Only if time permits.

Level 2: Revision Engineering

Lecture 6.3: The Forgetting Curve

Reality: You will forget 70% of what you study within 24 hours unless you interrupt the forgetting curve.

Active Recall Schedule

Rule: Revision is NOT re-reading. Revision is retrieval (testing yourself).

Check 2: Revision Logic

Q2. Which method generates the strongest memory retention?

Answer: Active Recall. Forcing your brain to 'fetch' data strengthens the neural pathway. Passive reading does not.

Level 3: Error Analytics

Lecture 6.4: The Error Log

Strategy: A mock test without analysis is a waste of 2 hours. You must categorize every lost mark.

Error Taxonomy

Type A (Silly): Read wrong, clicked wrong. (Fix: Focus)

Type B (Concept): Didn't know logic. (Fix: Re-study)

Type C (Guess): Fluke that went wrong. (Fix: Stop guessing)
