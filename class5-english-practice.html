💡 Quick Revision Notes

▼
Sentence Structure: Subject (doer) + Verb (action) + Object (receiver).
Nouns: Abstract nouns name ideas/feelings (e.g., happiness, courage).
Tenses: V1 (Present), V2 (Past), V3 (Past Participle). Use V3 with has/have/had.
Adjectives: Order: Quantity -> Quality -> Size -> Age -> Color -> Origin -> Material.
Punctuation: Use commas for pauses, lists, and before coordinating conjunctions (FANBOYS).
Writing: A paragraph needs a topic sentence, supporting details, and a concluding sentence.
