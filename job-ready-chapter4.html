Lecture 4.1: Excel Foundations & Data Structure

Structured Data Design

Before analysis, data must be clean. In corporate India, messy data is the #1 enemy of analysts.

Rule The "Golden Record" Standard:
  • Header Row: Unique, bold, no blanks.
  • No Merged Cells: Breaks pivot tables.
  • Consistent Types: Dates as Dates, Numbers as Numbers.
[Diagram: Clean Table vs Messy Table Structure]

Core Logical Formulas

Logic drives decisions. Memorize these:

  • IF(logical_test, val_if_true, val_if_false): Basic decision making.
  • SUMIF(range, criteria, sum_range): Adding specific sales (e.g., Total Sales in Mumbai).
  • COUNTIF(range, criteria): Counting occurrences (e.g., How many orders > ₹5000).
Example Scenario: Reliance Retail analyzing bill values.
Formula: =IF(B2>10000, "High Value", "Standard")

Reference Types (The $ Sign)

Crucial for copying formulas.

  • Relative (A1): Moves when you copy. Good for row-by-row calc.
  • Absolute ($A$1): Locked. Good for GST rates or fixed targets.

Lecture 4.2: Business Analysis & Pivots

Pivot Tables: The Analyst's Sword

Used to summarize 1 million rows in 5 seconds.

  1. Rows: Categorical data (Product Name).
  2. Columns: Time or Segment (Year, Region).
  3. Values: Metrics (Sum of Revenue, Count of Orders).
  4. Filters: Slicers (Country, Manager).
[Diagram: Pivot Table Four Quadrant Layout]

Dashboard Principles

Dashboards are for decision makers (CEOs, Managers).

Tip The 5-Second Rule: If a manager can't understand the status in 5 seconds, the dashboard failed.

KPI (Key Performance Indicator): A quantifiable measure of success.
Example: Flipkart's "Daily Active Users" or "Cart Abandonment Rate".

What-If Analysis

Goal Seek: Working backwards. "If I want ₹10 Lakh profit, how many units must I sell?"

Data Tables: Sensitivity analysis. Changing interest rates to see EMI impact.

Lecture 4.3: Advanced Analytics & Stats

Nested Logic

Combining IF, AND, OR.

=IF(AND(Sales>Target, Attendance>90%), "Bonus", "No Bonus")

Forecasting & Regression

Predicting the future based on history.

Linear Regression (y = mx + c): Finding the trend line.

  • y: Dependent variable (Sales).
  • x: Independent variable (Ad Spend).
  • R-Squared: Reliability of the trend (0 to 1). Closer to 1 is better.
[Diagram: Regression Line Scatter Plot with Trendline]

Data Storytelling

Don't just show numbers. Tell a story.

Structure: Context -> Insight -> Recommendation.

Bad "Sales dropped 10%."
Good "Sales dropped 10% because of supply chain strike in Gujarat. We recommend shifting to Maharashtra suppliers."
Lecture 4.4: Business Intelligence (BI)

The BI Ecosystem

When Excel isn't enough (Data > 10 Lakh rows), we use BI tools.

  • Power Pivot: Excel on steroids. Handles millions of rows.
  • DAX (Data Analysis Expressions): The formula language of Power BI.
  • Power BI / Looker Studio: Visualization tools for live, interactive sharing.
[Diagram: Data Source -> Power Query -> Data Model -> Dashboard]

Scenario Analysis

Preparing for uncertainty.

  • Best Case: Market grows 20%.
  • Base Case: Market grows 5%.
  • Worst Case: Market shrinks 10%.

Formula Cheat Sheet

  • VLOOKUP: Vertical search. =VLOOKUP(lookup_val, table, col_index, FALSE)
  • INDEX+MATCH: Better VLOOKUP.
  • IFERROR: Clean errors. =IFERROR(formula, 0)
  • CONCATENATE: Join text. =A1 & " " & B1

Dashboard Rules

  1. Keep it simple (KISS).
  2. Most important data top-left.
  3. Consistent colors.
  4. Interactive slicers required.
