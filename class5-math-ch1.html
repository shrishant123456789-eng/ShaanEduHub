Class 5 Mathematics

Chapter 1: Numbers & Number System

📝 Quick Notes
1. Natural & Whole Numbers
Natural Numbers start from 1 (1, 2, 3...). Whole numbers include 0 (0, 1, 2, 3...).
Example: 5 is Natural & Whole. 0 is only Whole.
[Image: Number Line starting 0 vs 1]
💡 Tip: "N" for Natural, "No zero". "W" for Whole, "Whole includes hole (0)".
2. Place Value & Face Value
Face Value is the digit itself. Place Value depends on position.
In 5,432: 4 is in Hundreds place. Place Value = 400. Face Value = 4.
[Image: Place Value Chart up to 10 digits]
💡 Tip: Face never changes (like your face!). Place changes with position.
3. Indian Number System
Periods: Ones, Thousands, Lakhs, Crores.
Commas: 3, 2, 2, 2... (from right).
Example: 12,34,56,789
[Image: Indian Place Value Chart]
4. International Number System
Periods: Ones, Thousands, Millions, Billions.
Commas: Every 3 digits.
Example: 123,456,789
[Image: International Place Value Chart]
5. Reading Large Numbers
Read the number in the period, then say the period name (except Ones).
Ex: 5,00,000 = Five Lakh.
[Image: Number Name Examples]
6. Expanded Form
Breaking a number into sum of place values.
452 = 400 + 50 + 2.
[Image: Expansion Diagram]
7. Comparing Numbers
1. Count digits (more digits = bigger). 2. If same, compare left-most digit.
[Image: Alligator Signs < > =]
8. Rounding Off
To nearest 10: Check ones digit. < 5 round down, >= 5 round up.
73 -> 70. 78 -> 80.
[Image: Rounding Hill Diagram]
9. Estimation
Quickly guessing a value close to actual answer.
52 + 48 ≈ 50 + 50 = 100.
[Image: Shopping Bill Estimation]
10. Even & Odd
Even ends in 0, 2, 4, 6, 8. Odd ends in 1, 3, 5, 7, 9.
[Image: Pairs vs Single items]
11. Prime & Composite
Prime: Only 2 factors (1 and itself). Ex: 2, 3, 5, 7.
Composite: More than 2 factors. Ex: 4, 6, 8, 9.
1 is neither Prime nor Composite.
[Image: Sieve of Eratosthenes]
12. Factors & Multiples
Factors divide exactly (Small). Multiples multiply (Big).
Factors of 6: 1, 2, 3, 6.
Multiples of 6: 6, 12, 18...
[Image: Factor Tree]
13. Divisibility Rules
2: Even last digit. 3: Sum of digits / 3. 5: Ends in 0 or 5. 10: Ends in 0.
[Image: Divisibility Chart]
14. Common Factors
Factors shared by two numbers.
Factors of 4: 1, 2, 4. Factors of 6: 1, 2, 3, 6. Common: 1, 2.
[Image: Venn Diagram]
15. HCF & LCM
HCF: Highest Common Factor (Greatest divisor).
LCM: Lowest Common Multiple (Smallest number divisible by both).
[Image: HCF/LCM Calculation steps]
16. Word Problems
Read -> Understand -> Plan -> Solve -> Check. Look for keywords: "Total" (+), "Difference" (-), "Product" (x), "Shared" (÷).
[Image: Problem Solving Steps]
