📚 Study Notes

1. Text Tool
Definition: Text Tool is used to type words or sentences in a drawing.
Explanation: With the Text Tool, we can write names, titles, or short messages on pictures. It helps us add words to our drawings.
Example: Writing "My House" on a drawing of a house.
Memory Tip: Text Tool = Type Words
Quick Check: Which tool is used to write words in Paint? (Answer: Text Tool)
[Text Tool Image]
2. Line Tool
Definition: Line Tool is used to draw straight lines.
Explanation: It helps us make borders, roads, or simple shapes using straight lines.
Example: Drawing a straight road.
Memory Tip: Line Tool = Straight Line
Quick Check: Can we draw curved lines with Line Tool? (Answer: No)
[Line Tool Image]
3. Curve Tool
Definition: Curve Tool is used to draw curved lines.
Explanation: It helps in drawing waves, smiles, or bends.
Example: Drawing a rainbow shape.
Memory Tip: Curve Tool = Bend the line
Quick Check: Which tool makes a line bend? (Answer: Curve Tool)
[Curve Tool Image]
4. Rectangle Tool
Definition: Rectangle Tool is used to draw rectangular shapes.
Explanation: It helps us draw boxes, doors, and books.
Example: Drawing a door.
Memory Tip: Rectangle = Box Shape
Quick Check: Which tool is used to draw a box? (Answer: Rectangle Tool)
[Rectangle Tool Image]
5. Circle Tool
Definition: Circle Tool is used to draw circles and ovals.
Explanation: It helps us draw balls, sun, or wheels.
Example: Drawing a football.
Memory Tip: Circle Tool = Round Shape
Quick Check: Which tool draws round shapes? (Answer: Circle Tool)
[Circle Tool Image]
6. Polygon Tool
Definition: Polygon Tool is used to draw shapes with many sides.
Explanation: It helps us draw triangles, stars, or kites.
Example: Drawing a triangle.
Memory Tip: Polygon = Many sides
Quick Check: Can Polygon Tool draw triangles? (Answer: Yes)
[Polygon Tool Image]
7. Select Tool
Definition: Select Tool is used to select a part of a picture.
Explanation: We can move, cut, or copy the selected part.
Example: Moving a flower in a drawing.
Memory Tip: Select = Choose Part
Quick Check: Which tool selects a picture part? (Answer: Select Tool)
[Select Tool Image]
8. Resize Tool
Definition: Resize Tool is used to make a picture bigger or smaller.
Explanation: It helps adjust picture size.
Example: Making a small sun bigger.
Memory Tip: Resize = Change Size
Quick Check: Which tool changes picture size? (Answer: Resize Tool)
[Resize Tool Image]
9. Rotate Tool
Definition: Rotate Tool is used to turn a picture.
Explanation: It can turn pictures left, right, or upside down.
Example: Turning a leaf picture.
Memory Tip: Rotate = Turn Around
Quick Check: Which tool turns pictures? (Answer: Rotate Tool)
[Rotate Tool Image]
10. Undo and Redo
Definition: Undo removes the last action. Redo brings it back.
Explanation: These tools fix mistakes easily.
Example: Undo wrong color, redo correct color.
Memory Tip: Undo = Go Back, Redo = Go Again
Quick Check: Which tool fixes mistakes? (Answer: Undo)
[Undo Redo Image]
11. Opening an Existing Picture
Definition: Opening an existing picture means opening a saved drawing.
Explanation: We can edit old pictures again.
Example: Opening yesterday's drawing.
Memory Tip: Open = Use Old Picture
Quick Check: Can we edit saved pictures? (Answer: Yes)
[Open Image]

Answer: Circle Tool

29. What happens with Redo?
Answer: Brings back the undone action

Explanation: These three tools draw different shapes.
