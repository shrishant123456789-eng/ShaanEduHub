Formatting in Word

📘 Smart Notes

TOPIC 1: Selecting Text

Definition: Selecting text means choosing a word or sentence to change it.

Explanation: Before formatting, we must select the text. Selected text becomes highlighted.

Example: Selecting a word to make it bold.

Memory Tip: Select First, Change Later

TOPIC 2: Font Size

Definition: Font size means how big or small the text is.

Explanation: We can increase or decrease text size to make it clear.

Example: Making heading text bigger.

Memory Tip: Big Size = Big Text

TOPIC 3: Font Style

Definition: Font style means the design of letters.

Explanation: Different font styles make text look different.

Example: Changing text style for title.

Memory Tip: Style = Look

TOPIC 4: Bold Text

Definition: Bold makes text darker and thicker.

Explanation: It is used to highlight important words.

Example: Bold heading text.

Memory Tip: Bold = Dark Text

TOPIC 5: Italic Text

Definition: Italic makes text slanted.

Explanation: It is used for special words.

Example: Italic name of book.

Memory Tip: Italic = Slant

TOPIC 6: Underline Text

Definition: Underline puts a line under text.

Explanation: It highlights important text.

Example: Underline heading.

Memory Tip: Underline = Line Below

TOPIC 7: Font Color

Definition: Font color changes the color of text.

Explanation: Colored text looks attractive.

Example: Red color for heading.

Memory Tip: Font Color = Text Color

TOPIC 8: Text Alignment

Definition: Text alignment means placing text properly.

Explanation: Text can be left, center, or right aligned.

Example: Center aligned heading.

Memory Tip: Alignment = Text Position

TOPIC 9: Bullets and Numbering

Definition: Bullets and numbering organize text in list form.

Explanation: They make points easy to read.

Example: List of fruits using bullets.

Memory Tip: Bullets = Points

TOPIC 10: Inserting Pictures

Definition: Inserting pictures means adding images to document.

Explanation: Pictures make documents attractive.

Example: Adding school image.

Memory Tip: Picture = Image Add

TOPIC 11: Inserting Shapes

Definition: Inserting shapes means adding shapes like circle or rectangle.

Explanation: Shapes are used for design.

Example: Adding rectangle for heading.

Memory Tip: Shapes = Designs
