Lecture 5.1: Workflow Fundamentals

Process Mapping & Visualization

Before automating, you must understand the flow. Process Mapping is the visual representation of work.

  • Flowcharts: Standard step-by-step diagrams (Start, Decision, Process, End).
  • Swimlane Diagrams: Shows who does what by separating actors into lanes.
[ Diagram: Swimlane showing HR, Employee, and Manager lanes ]

Identifying Bottlenecks

A bottleneck is a point of congestion. The output of a system is limited by its tightest bottleneck.

Case Study (Indian Manufacturing): A textile plant in Gujarat produced 500 units/hour but the packaging machine could only handle 300 units/hour. Automation at the weaving stage was useless until packaging was upgraded.

Standard Operating Procedures (SOPs)

Automation requires rules. SOPs document these rules. Without an SOP, a computer cannot follow instructions.

Lecture 5.2: Automation Systems

Trigger-Based Logic

Most automation follows the IF THIS, THEN THAT (IFTTT) model.

  • Trigger: The event that starts the flow (e.g., New email received).
  • Condition: Logic check (e.g., Subject contains "Invoice").
  • Action: What the system does (e.g., Save attachment to Drive).
[ Diagram: Trigger (Email) → Condition (Subject Check) → Action (Save File) ]

Task Batching vs. Real-Time

Real-time: Runs immediately (e.g., OTP SMS).
Batching: Runs at set intervals (e.g., Daily sales report at 6 PM). Saves server resources.

Lecture 5.4: ROI & Optimization Strategy (Expert)

Calculating Automation ROI

Is automation worth it? Use this formula:

ROI = (Time Saved × Hourly Cost) - Tool Cost

Example: Automating a report saves 5 hours/week. Employee cost ₹500/hr. Tool costs ₹2000/month.
Savings = (20 hrs × ₹500) = ₹10,000.
Net Benefit = ₹8,000/month.

The Decision Pipeline

Not everything should be automated. Use the Hybrid Escalation Model:

  1. Level 1: Bot handles FAQs (Instant).
  2. Level 2: Complex queries routed to Junior Human Agent.
  3. Level 3: Critical issues routed to Manager.

❗ Important Questions (Interview Prep)

Q1. What is an API?

Application Programming Interface - allows two apps to talk to each other.

Q2. Define a webhook.

A way for an app to provide other applications with real-time information.

Q3. What is RPA?

Robotic Process Automation - bots that mimic human actions on UI.

Q4. Difference between trigger and polling?

Trigger is instant (push); Polling checks periodically (pull).

Q5. What is a dependency?

When one task cannot start until another is finished.

Q6. Explain 'Scalability' in automation.

Ability of the system to handle increased volume without breaking.

Q7. What is Exception Handling?

Logic defined to handle errors when the automation fails.

Q8. Name 3 automation risks.

Over-engineering, lack of human oversight, security vulnerabilities.

Q9. What is a 'Zap'?

A unit of workflow in Zapier consisting of a trigger and action.

Q10. How to calculate FTE savings?

Full Time Equivalent = Hours Saved / Hours a full-time employee works.
