Class Notes 📝

1. Concept of Files and Folders

Definition: A FILE is like a single sheet of paper where you store your work (drawing, poem, letter). A FOLDER is like a bag or a box where you keep many files together.

🇮🇳 Indian Daily Life Example:
Think of your School Bag as the Main Hard Drive.
Your Lunch Box is a Folder.
Inside it, the Roti and Sabzi are Files!
IMAGE: Drawing of a paper (file) going into a yellow folder
💡 Tip: Files have data. Folders have files.
2. Creating Files and Folders

To keep things organized, we must create new folders.

Steps to Create a Folder:

  1. Right-click on an empty space.
  2. Select NEW.
  3. Click on FOLDER.
  4. Type a name and press Enter.
IMAGE: Screenshot of Right Click Context Menu -> New -> Folder
💡 Tip: Right-Click is your magic wand!
3. Renaming Files and Folders

Renaming means changing the name of a file or folder.

Why? If you name everything "New Folder", you will get confused!

Steps:

  1. Right-click the file/folder.
  2. Select RENAME.
  3. Type the new name (e.g., "Homework").
  4. Press Enter.
🇮🇳 Example: Just like we label our school notebooks "Maths", "English" so we don't pick the wrong one!
4. Opening and Saving Files

Opening: Double-click (click twice fast) with the left mouse button to open a file.

Saving: When you finish work, you MUST save it so it doesn't get lost.

Shortcut: Ctrl + S

IMAGE: Icon of a Floppy Disk (Save Button)
💡 Tip: Save often, or cry later!
5. Moving and Deleting

Moving (Cut & Paste): Changing the location of a file.

Deleting: Removing a file you don't need.

Deleted files go to the Recycle Bin (Computer's Dustbin).

🇮🇳 Example: Throwing waste paper in the dustbin (Delete). Putting books from table to shelf (Move).
6. Searching a File/Folder

Can't find your drawing? Use the Search Bar.

Located at the top right of the file explorer window.

Just type the name, and the computer finds it for you!

IMAGE: Magnifying glass icon in a search bar
7. Basic Organization Practices

Do not keep all files on the Desktop! It makes the computer slow and messy.

Create main folders like: Music, Photos, School Work, Games.

💡 Tip: A clean desktop = A happy computer.
8. Why Organization Matters
  1. Saves Time: You find things quickly.
  2. Less Stress: You don't lose important homework.
  3. Looks Good: Neat and tidy.
🇮🇳 Example: If your room is messy, can you find your socks? No! Same with computer files.
