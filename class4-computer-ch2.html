1. Overview of a Computer System

A computer is a smart machine that works on electricity. It takes input from us, processes it, and gives us output. This is called the I-P-O Cycle.

[Image: Diagram of Input -> Process -> Output]
🏠 Home Example: Think of making Mango Shake in a mixer!
• Input: Mango slices, milk, sugar.
• Process: Mixer grinder spinning.
• Output: Yummy Mango Shake.
💡 Tip: Remember I-P-O like "In - Process - Out".
❓ Quick Check: In the human body, which part does the "Processing"?
(Answer: The Brain)

2. Hardware vs Software

A computer has two main parts: Hardware and Software.

Hardware: The physical parts of a computer that you can touch and feel.

Software: The set of instructions or programs that tell the hardware what to do. You cannot touch software.

[Image: Split screen showing Monitor (HW) vs MS Paint Icon (SW)]
🏫 School Example:
• Your Notebook is Hardware (you can touch it).
• The Stories written inside are Software (you read them, but can't physically hold the story).
💡 Tip: Hard = Solid (Touch). Soft = Logic (No Touch).

3. Main Hardware Components

Every computer has 4 main parts:

  • Monitor: Looks like a TV. Shows us movies, games, and work (Output).
  • CPU (Central Processing Unit): The "Brain" of the computer. It does all calculations inside the System Unit box.
  • Keyboard: Has many keys to type letters and numbers (Input).
  • Mouse: A pointing device used to click and draw (Input).
[Image: Labeled diagram of a Desktop Computer]
❓ Quick Check: Which part is called the VDU (Visual Display Unit)?
(Answer: The Monitor)

4. Peripheral Devices

Devices connected to the CPU by wires are called Peripherals.

  • Printer: Prints work on paper (Hard Copy).
  • Speakers: Helps us hear music and sound.
  • Scanner: Copies a photo/paper into the computer.
  • Webcam: A camera for video calls.
🏢 Office Example: When Papa takes a printout of a ticket, the Printer gives the paper output.

5. Input vs Output Devices

We group devices based on their job:

Input Devices (Sending In): Keyboard, Mouse, Scanner, Microphone, Joystick.

Output Devices (Showing Out): Monitor, Printer, Speakers, Headphones.

💡 Tip: If it helps you "Tell" the computer something, it is Input. If the computer "Tells" you something, it is Output.
