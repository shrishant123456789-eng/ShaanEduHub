📚 Study Notes

1. What is Paint?
Definition: Paint is a drawing program used to make pictures on a computer.
Explanation: Paint helps children draw, color, and design pictures using tools. It is easy and fun to use.
Example: Drawing a house using mouse.
Memory Tip: Paint = Drawing App
Quick Check: Is Paint used for drawing or typing? (Answer: Drawing)
[Paint Program Image]
2. Starting Paint
Definition: Starting Paint means opening the Paint program.
Explanation: Paint can be opened by clicking Start → All Apps → Paint.
Example: Opening Paint before drawing.
Memory Tip: Start → Paint
Quick Check: Where do we open Paint from? (Answer: Start Menu)
[Start Paint Image]
3. Parts of Paint Window
Definition: Parts of Paint window are different sections of Paint.
Explanation: Paint window has title bar, ribbon, tools area, color box, and drawing area.
Example: Choosing color from color box.
Memory Tip: Tools + Colors + Drawing Area
Quick Check: Where do we draw in Paint? (Answer: Drawing Area)
[Paint Window Image]
4. Pencil Tool
Definition: Pencil tool is used to draw thin free-hand lines.
Explanation: It works like a pencil on paper.
Example: Drawing grass.
Memory Tip: Pencil = Thin Line
Quick Check: Which tool draws thin lines? (Answer: Pencil Tool)
[Pencil Tool Image]
5. Brush Tool
Definition: Brush tool is used to draw thick lines.
Explanation: It gives different brush styles.
Example: Painting tree branches.
Memory Tip: Brush = Thick Line
Quick Check: Which tool draws thick lines? (Answer: Brush Tool)
[Brush Tool Image]
6. Eraser Tool
Definition: Eraser tool removes unwanted drawing.
Explanation: It helps correct mistakes.
Example: Removing wrong line.
Memory Tip: Eraser = Remove
Quick Check: Which tool removes mistakes? (Answer: Eraser Tool)
[Eraser Tool Image]
7. Color Box
Definition: Color box shows different colors.
Explanation: We choose colors from it.
Example: Choosing red color for apple.
Memory Tip: Color Box = Colors
Quick Check: Where do we select colors? (Answer: Color Box)
[Color Box Image]
8. Shapes Tool
Definition: Shapes tool is used to draw ready-made shapes.
Explanation: It includes circle, rectangle, line, etc.
Example: Drawing sun using circle.
Memory Tip: Shapes = Ready Shapes
Quick Check: Which tool draws ready shapes? (Answer: Shapes Tool)
[Shapes Tool Image]
9. Fill with Color Tool
Definition: Fill tool fills color inside shapes.
Explanation: Click inside shape to fill color.
Example: Filling blue color in sky.
Memory Tip: Fill = Color Inside
Quick Check: Which tool fills color? (Answer: Fill Tool)
[Fill Tool Image]
10. Saving a Drawing
Definition: Saving a drawing means storing it in computer.
Explanation: Saved drawings can be opened later.
Example: Saving drawing as MyHouse.
Memory Tip: Save = Store Work
Quick Check: Why do we save drawings? (Answer: To store them)
[Save Image]
