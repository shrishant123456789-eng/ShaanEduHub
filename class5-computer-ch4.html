📘 Study Notes

1. Functions of OS

The Operating System is like the "Manager" of the computer. It handles three main jobs:

  • Process Management: Decides which program (app) uses the CPU.
  • Memory Management: Decides where to store data in RAM or Hard Disk.
  • File Management: Saves, deletes, and organizes your files in folders.
🖼️ [Diagram: OS in center, connecting Hardware & User]
🏠 Daily Life Example:
Think of the OS as the Principal of a School. The Principal decides which class goes to the playground (Process), which room is for which class (Memory), and keeps student records safe (File).
💡 Tip: Remember "PMF" - Process, Memory, File.
2. Types of OS
  • Single User OS: Only one person can work at a time. (e.g., Your home laptop).
  • Multi User OS: Many people use the same computer at the same time via network. (e.g., Servers, Supercomputers).
  • Real Time OS (RTOS): Works strictly on time. No delays allowed! (e.g., Robots, Missile launches).
🖼️ [Diagram: Icons for Single User vs Server Network]
🏠 Daily Life Example:
Single User: A bicycle (only one person rides).
Multi User: A bus (many people travel together).
3. Examples of OS
  • Windows: Made by Microsoft. Easy to use. Most popular (GUI).
  • Linux: Free and Open Source. Very secure. Used by hackers and servers.
  • Android: Made by Google. Used in Mobile Phones and Tablets.
🖼️ [Logos: Windows Flag, Penguin, Green Robot]
💡 Tip: Android is for phones, Windows is for PC work!
4. Booting Process

Booting is the process of loading the OS from Hard Disk to RAM when computer starts.

  • Cold Boot: Turning on the computer from a completely OFF state (Power Button).
  • Warm Boot: Restarting the computer while it is already ON (Restart button).
🏠 Daily Life Example:
Cold Boot: Waking up in the morning after sleeping all night.
Warm Boot: Washing your face in the afternoon to feel fresh.

❓ Important Questions

Q1. What is the kernel?
Ans: The core part of the OS that controls hardware directly.

Q2. Why is Memory Management needed?
Ans: To ensure one program doesn't use all the RAM and crash others.

Q3. Which OS is used in Mars Rovers?
Ans: Real Time OS (RTOS) because delays are dangerous in space.
