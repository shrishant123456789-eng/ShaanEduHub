📝 CHAPTER NOTES

1. What is a Presentation?

A presentation is a way to show and explain information to an audience using text, pictures, and sound. It is like digital storytelling!

Microsoft PowerPoint is a popular software used to create presentations.

📌 Indian School Example: Remember when the Principal shows slides on the big screen during the Morning Assembly? That is a PowerPoint Presentation!
🧠 Tip: Think of it as a "Digital Chart Paper".
[IMAGE: A cartoon teacher pointing to a projector screen]
2. Opening & Closing PowerPoint

To Open:

  1. Click on the Start button.
  2. Scroll down to 'M' or 'P'.
  3. Click on PowerPoint.

To Close: Click the 'X' button on the top right corner or go to File > Close.

🧠 Tip: Look for the red-orange icon with a 'P'.
[IMAGE: Screenshot of Windows Start Menu highlighting PowerPoint]
3. Creating Slides

A Slide is a single page in a presentation.

When you open PowerPoint, it creates a "Blank Presentation". The first slide is usually the Title Slide.

New Slide: Go to Home Tab > Click "New Slide".

📌 Example: Just like your notebook has many pages, a presentation has many slides.
[IMAGE: The Home Ribbon showing the New Slide button]
4. Adding Text to Slides

You cannot write directly on the blank space. You must use Placeholders (dashed boxes).

1. Click inside the box that says "Click to add title".
2. Type your topic name (e.g., "My Hobby").
3. Formatting: Use the Font Group in the Home Tab (Bold, Italic, Color).

[IMAGE: A slide with 'Click to add title' placeholder selected]
5. Applying Slide Design

Make your slides colorful!

1. Click on the Design Tab.
2. Choose a Theme from the list.
3. The design applies to all slides automatically.

📌 Example: It is like wrapping your project file with a beautiful cover paper.
[IMAGE: The Design Tab showing colorful themes]
6. Images & Animations

Insert Image: Insert Tab > Pictures > This Device.

Animation: Making text or images move.

1. Select the object.
2. Go to Animations Tab.
3. Choose an effect (e.g., Fly In, Float In).

🧠 Tip: Don't use too many animations, it distracts the audience!
[IMAGE: Animation pane with a 'Fly In' effect selected]
7. Slide Show Basics

To show your presentation to the class fullscreen.

Start Show: Press F5 key on keyboard.

Next Slide: Press Spacebar or Enter or Click Mouse.

End Show: Press Esc key.

[IMAGE: Keyboard highlighting F5 and Esc keys]
8. Saving & Reopening

Saving: File > Save As > Browse > Type Name > Save.

Extension is .pptx

Reopening: File > Open > Select your file.

📌 Important: Always save your work every 10 minutes so you don't lose it if power goes off!
[IMAGE: The File > Save As menu screen]

🌟 IMPORTANT QUESTIONS

Q1: What is a Slide Show?
Ans: A slide show is the digital presentation of slides on a full screen, shown one by one to an audience.

Q2: What is the file extension of PowerPoint 2016?
Ans: The file extension is .pptx.

Q3: Which key is used to start a slide show from the beginning?
Ans: The F5 function key.

Q4: What is a Placeholder?
Ans: A placeholder is a dotted box on a slide layout where you can add text, pictures, or charts.

Q5: Name the tab used to change the background design.
Ans: The Design tab.
