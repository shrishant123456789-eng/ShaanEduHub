🎯 Important Questions

Q1. What is a word processor?

Answer: It is a program used to type text.
Explanation: It helps create documents.

Q2. Name one word processor.

Answer: MS Word
Explanation: It is commonly used.

Q3. What is MS Word used for?

Answer: Typing and editing text.
Explanation: It makes documents.

Q4. What are the main parts of Word window?

Answer: Title bar, ribbon, document area, and status bar.
Explanation: These sections help us work easily.

Q5. Where do we type text in MS Word?

Answer: In the document area.
Explanation: It is the white page in the middle.

Q6. What is a new document?

Answer: A blank page in MS Word.
Explanation: We start fresh work here.

Q7. Why do we create a new document?

Answer: To type fresh work.
Explanation: It gives us a clean page.

Q8. What does typing text mean?

Answer: Writing words using keyboard.
Explanation: We press keys to write.

Q9. Which device is used for typing?

Answer: Keyboard.
Explanation: It has all the letter keys.

Q10. What is saving a document?

Answer: Storing a document in computer.
Explanation: It keeps our work safe.

Q11. Why should we save a document?

Answer: So we can use it later.
Explanation: Otherwise work will be lost.

Q12. What is opening a document?

Answer: Using a saved document again.
Explanation: We can view old work.

Q13. Can we edit a saved document?

Answer: Yes.
Explanation: We can make changes anytime.

Q14. What is closing a document?

Answer: Exiting the document.
Explanation: We finish working on it.

Q15. Should we save before closing?

Answer: Yes.
Explanation: To keep our work safe.

Q16. What is the title bar?

Answer: The top bar showing the file name.
Explanation: It helps identify the file.

Q17. What is the ribbon?

Answer: The toolbar with tools and commands.
Explanation: It has formatting options.

Q18. What is the status bar?

Answer: The bottom bar showing page number.
Explanation: It gives information about the document.

Q19. How do we start MS Word?

Answer: By clicking on the Word icon.
Explanation: It opens the program.

Q20. What can we type in Word?

Answer: Letters, words, and sentences.
Explanation: Any text can be typed.

Q21. What is a document?

Answer: A file containing typed text.
Explanation: It stores our work.

Q22. Can we type a story in Word?

Answer: Yes.
Explanation: Word is good for long writing.

Q23. What happens if we do not save?

Answer: The work will be lost.
Explanation: Computer forgets unsaved work.

Q24. What is the file name?

Answer: The name given to a document.
Explanation: It helps identify the file.

Q25. How is typing on computer better than writing?

Answer: It looks neat and can be edited.
Explanation: We can correct mistakes easily.

Q26. What is the insertion point?

Answer: The blinking cursor where we type.
Explanation: It shows where text will appear.

Q27. What do we use Enter key for?

Answer: To go to a new line.
Explanation: It starts a new paragraph.

Q28. What do we use Spacebar for?

Answer: To give space between words.
Explanation: It separates words.

Q29. What is the Backspace key used for?

Answer: To delete letters.
Explanation: It removes text to the left.

Q30. Give two uses of word processor.

Answer: Typing letters and homework.
Explanation: We can do many writing tasks.
