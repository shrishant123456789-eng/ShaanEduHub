📝 My Study Notes

1. Terms of Addition

Addition is putting numbers together to find the total.

  • Addends: The numbers we add.
  • Sum: The answer we get.

2,500 (Addend) + 1,000 (Addend) = 3,500 (Sum)

Check: Can we change the order? Yes! 5 + 3 is same as 3 + 5.

2. Terms of Subtraction

Subtraction is taking away a number from another.

  • Minuend: The bigger number (Top).
  • Subtrahend: The number to be subtracted (Bottom).
  • Difference: The answer we get.

5,000 (Minuend) - 2,000 (Subtrahend) = 3,000 (Difference)

3. Checking Subtraction

We can check if our subtraction is correct using Addition!

💡 Formula: Difference + Subtrahend = Minuend

If 10 - 3 = 7, then check: 7 + 3 = 10. Correct!

4. Important Properties

  • Order Property: A + B = B + A (Addition only).
  • Zero Property: Number + 0 = Same Number.
  • Zero in Subtraction: Number - 0 = Same Number.
  • Self Subtraction: Number - Same Number = 0.

5. Regrouping (Carry & Borrow)

Addition (Carry Over): If a column adds to more than 9, carry the tens digit to the next left column.

Subtraction (Borrow): If top digit is smaller than bottom digit, borrow 1 from the left neighbour.

[Image: Borrowing 1 Ten to make 15 Ones]

6. Estimating Sums & Differences

Estimation means finding a "rough" answer by Rounding Off first.

Estimate 52 + 38:

Round 52 -> 50

Round 38 -> 40

Estimated Sum = 50 + 40 = 90

7. Word Problem Keywords

Look for these words to decide what to do:

  • ➕ ADD: Total, Sum, Altogether, In all, Put together.
  • ➖ SUBTRACT: Difference, Left, Remaining, How much more, How much less.

Q1: What is the result of Addition called?

Ans: Sum

Q2: What is the result of Subtraction called?

Ans: Difference

Q3: 99,999 + 1 = ?

Ans: 1,00,000

Q4: 10,000 - 1 = ?

Ans: 9,999

Q5: Order property works for Subtraction. (True/False)

Ans: False (5-3 is not 3-5)

Ans: 9999 + 100 = 10,099

Q7: Minuend = Difference + _________?

Ans: Subtrahend

Ans: 100 - 45 = 55

Q9: 1 Lakh - 1 Ten Thousand = ?

Ans: 90,000

Q10: If we add 0 to a number, the sum is?

Ans: The number itself.

Ans: 3950

Ans: Addends

Q14: 543 + 219 = 219 + ____?

Ans: 543

Q15: 1000 - 0 = ?

Ans: 1000

Q16: 500 - 500 = ?

Ans: 0

Q17: To estimate sum of 42 and 58, we round to nearest?

Ans: Tens (40 + 60 = 100)

Q18: In 50 - 20 = 30, which is the Minuend?

Ans: 50

Q19: In 50 - 20 = 30, which is the Subtrahend?

Ans: 20

Q20: Difference between smallest 6-digit no. and largest 5-digit no.?

Ans: 1 (1,00,000 - 99,999)

Q21: When we subtract 1 from a number, we get its?

Ans: Predecessor

Q22: When we add 1 to a number, we get its?

Ans: Successor

Q23: 800 + 200 - 100 = ?

Q24: By how much is 500 greater than 300?

Q25: 75 + 25 = 100. So, 100 - 75 = ?

Q27: Sum of 4000 and 6000?

Ans: 10,000

Q28: Can we add three numbers in any order?

Ans: Yes (Associative Property)

Q29: 1234 + 0 = ?

Ans: 1234

Q30: Is the sum always bigger than the addends?

Ans: Yes, unless adding 0.

⚡ Quick Revision

  • ADDITION: Combining numbers. Order doesn't matter.
  • SUBTRACTION: Finding the difference. Order matters!
  • Sum + 0 = Sum. Difference - 0 = Difference.
  • Minuend is the TOP number (Big).
  • Subtrahend is the BOTTOM number (Small).
  • To check subtraction: Add Difference + Subtrahend.
  • Keywords: 'Total' means Add, 'Left' means Subtract.
  • Estimate by rounding off first.
