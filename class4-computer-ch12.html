📚 Chapter Notes

1. Practical Projects Using Learned Tools

Definition: Using software like Word, Paint, and Calculator together to solve a problem or create something new.

Steps: 1. Plan what you want to make. 2. Choose the right tool (Paint for drawing, Word for writing). 3. Combine them.

[IMAGE: Screen showing MS Word with a picture pasted from MS Paint]

Example: Creating a Birthday Invitation using Paint for balloons and Word for the text.

💡 Tip: Always save your work often using Ctrl + S!
2. Creating a Digital Poster (Word + Paint)

Definition: A digital document that uses big text and images to share a message.

Steps: Open MS Word -> Page Layout -> Page Color -> Insert WordArt for Title -> Insert Pictures.

[IMAGE: A colorful poster about 'Save Trees' created in MS Word]

Example: Making a "Republic Day" poster for your school notice board.

🎨 Tip: Use bright colors and simple fonts for posters.
3. File Organization Project

Definition: Keeping your computer clean by putting files into correct folders.

Steps: Right-click on Desktop -> New -> Folder -> Type Name (e.g., "Homework") -> Drag files into it.

[IMAGE: A folder structure: School -> Class 4 -> Subjects -> Computer]

Example: Creating separate folders for "Maths", "English", and "Computer" on your home PC.

📁 Tip: Never delete a file if you don't know what it is!
4. Creating a Simple Presentation

Definition: Showing information slide by slide using PowerPoint or Impress.

Steps: Open PowerPoint -> Click "Click to add title" -> Type Topic -> New Slide -> Add Content.

[IMAGE: PowerPoint slide view showing a Title Slide and a Picture Slide]

Example: A 3-slide presentation on "My Favorite Animal".

🖥️ Tip: Keep text small. Pictures speak louder than words!
5. Internet Research & Safe Reporting

Definition: Finding information on Google responsibly and using it for homework.

Steps: Open Browser -> Go to Google.com -> Type keywords (e.g., "History of Taj Mahal") -> Read -> Write in your own words.

[IMAGE: Google search bar with 'Safe Search' lock icon visible]

Example: Finding out who invented the Computer for a school project.

🔒 Tip: Never talk to strangers online while researching.
6. Practice Tests & Quizzes

Definition: Using computer programs or websites to test your knowledge.

Activity: Taking an online typing test to improve speed.

[IMAGE: Screen showing a typing tutor game with wpm score]

Example: Using a math quiz app.

⚡ Tip: Treat computer quizzes like real exams. No cheating!
7. Digital Citizenship and Ethics

Definition: Being a good person while using the internet (Netiquette).

Rules: Be polite, don't copy-paste without permission, respect privacy.

[IMAGE: Icons representing 'Be Kind', 'No Bullying', 'Respect Privacy']

Example: Not typing in ALL CAPS because it looks like shouting.

🤝 Tip: If you wouldn't say it to their face, don't type it!
8. Review & Assessment Tasks

Definition: Checking if everything works correctly before submitting.

Steps: Spell check in Word -> Slide show preview in PowerPoint -> Open links.

[IMAGE: A checklist with 'Spelling OK', 'Images OK', 'Saved OK' ticked]

Example: Reading your essay one last time before printing.

✅ Tip: Always "Preview" before "Print".
