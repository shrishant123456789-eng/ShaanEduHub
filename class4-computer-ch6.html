📚 My Computer Notebook

Topic 1: Introduction

What is MS Word?

MS Word is a Word Processing Software. It is like a digital notebook where we can type letters, stories, poems, and reports. It is part of the Microsoft Office package.

The icon looks like a blue "W".
🏠 Daily Life Example: Just like you use a diary to write your daily thoughts, adults use MS Word to write office letters!
💡 Remember: Word Processor = Software to Type and Edit text.
Topic 2: Creating New Document

Starting Fresh

To start writing, we need a blank page. This is called a Document.
Steps:
1. Click on File Tab.
2. Select New.
3. Click on Blank Document.
🎹 Keyboard Shortcut: Ctrl + N (N for New)
[ File ] [ Home ] [ Insert ] ...
⬇
New > Blank Page 📄
Topic 3: Typing Text

Let's Type!

When you open Word, you see a blinking vertical line. This is called the Cursor or Insertion Point.
• Use the Keyboard to type letters.
• Press Spacebar for gaps between words.
• Press Enter key to go to the next line.
🏫 Example: Creating a list of your friends for a birthday party invitation.
Topic 4: Editing Text

Making Changes

Editing means fixing mistakes or rearranging text.
1. Select: Drag mouse over text or use Shift + Arrow Keys.
2. Cut: Moves text (Removes from old place). ✂️ Ctrl + X
3. Copy: Duplicates text (Keeps in both places). 📄 Ctrl + C
4. Paste: Places the text. 📋 Ctrl + V
5. Undo: Go back one step. ↩️ Ctrl + Z
6. Redo: Cancel Undo. ↪️ Ctrl + Y
💡 Tip: X looks like Scissors (Cut). V looks like an arrow pointing down (Paste here).
Topic 5: Formatting Text

Making It Look Beautiful

Formatting means changing how text looks. All tools are in the Home Tab > Font Group.
• Font: Handwriting style (e.g., Arial, Calibri).
• Size: How big the letters are.
• B (Bold): Makes text dark and thick. (Ctrl+B)
• I (Italic): Slants the text. (Ctrl+I)
• U (Underline): Draws a line below. (Ctrl+U)
• Color: Changes text color (Red, Blue, etc.).
Home Tab: [ B ] [ I ] [ U ] [ A▼ ]
Topic 6: Paragraph Formatting

Organizing Lines

Alignment: Where text sits on the page.
• Left (Default)
• Center (For Titles)
• Right (For Dates)
• Justify (Even on both sides)

Lists:
• Bullets: For items without order (• Apple • Banana)
• Numbering: For steps (1. Wake up 2. Brush teeth)
Topic 7: Inserting Elements

Adding Visuals

To make documents fun, we add pictures!
Go to Insert Tab.
• Pictures: Add photos from your computer.
• Shapes: Add squares, circles, arrows, stars.
🇮🇳 Project: Making a poster on 'Save Tigers' with a tiger photo and a star shape saying "Act Now".
Topic 8: Saving & Closing

Keeping Safe

Always save your work so you don't lose it!
To Save:
1. Click File > Save.
2. Type a file name (e.g., "MyEssay").
3. Click Save.
Shortcut: Ctrl + S

To Close: Click the 'X' button on the top right corner.

  5. Which bar shows the document name? Title Bar

  9. What is the Ribbon? The panel at the top with tabs and commands.
  10. Which view is best for reading? Read Mode.

  12. Which tab has the Bold option? Home Tab.
  13. Shortcut to Print? Ctrl + P.
  14. What represents the mouse on screen? Pointer / Cursor.
  15. Can we insert online pictures? Yes.
  16. What is the white area called? Document Area / Workspace.
  17. How to center align text? Ctrl + E.
  18. What does the red wavy line mean? Spelling mistake.
  19. What does the blue wavy line mean? Grammar mistake.
  20. Tool to copy formatting only? Format Painter.
  21. How to capitalize all letters? Change Case > UPPERCASE.
  22. Where is the Quick Access Toolbar? Top left corner.
  23. How to undo a mistake? Click Undo arrow or Ctrl + Z.
  24. Can we add page borders? Yes, from Design/Page Layout tab.
  25. What is 'Hard Copy'? The printed paper.
  26. What is 'Soft Copy'? The file in the computer.
  27. Key to go to start of line? Home Key.
  28. Key to go to end of line? End Key.
  29. How to exit Word? Alt + F4 or Close button.
  30. Is Word a system software? No, it is Application Software.
