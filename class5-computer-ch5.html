📘 Chapter Notes

1. File vs. Folder

Definition File: The smallest unit of storage. It contains data like text, images, or music.
Folder: A container that stores files and other folders (sub-folders).

Basic → Advanced: Initially, we just save files. As experts, we organize them into folders to keep the computer tidy, just like a bookshelf.

🇮🇳 Daily Life Example: Ideally, a File is like a single sheet of homework paper. A Folder is like your School Bag that holds many papers and books.

[ 📄 File ] vs [ 📁 Folder ]

💡 Memory Tip: Files have extensions (.txt), Folders do not!

❓ Check: Can a folder contain another folder? Yes!

3. Folder Hierarchy

Tree Structure Files are organized in a tree-like structure. The main folder is the Root (usually Drive C:). Folders inside folders are called Sub-folders.

Path: The address of a file.
Ex: C:\Users\Student\Documents\Homework.docx

🌳 Root → Parent Folder → Child Folder → File
❓ Check: The top-most folder is called? Root

4. File Properties

Right-click a file and select Properties to see details.

  • Size: How much space it takes (KB, MB, GB).
  • Type: What kind of file it is.
  • Created: Date and time it was made.
  • Location: Where it is stored.
Properties Window: [ Size: 2 MB | Created: Today ]

5. Operations: Copy, Move, Delete

Copy (Ctrl + C): Makes a duplicate. Original stays.

Cut/Move (Ctrl + X): Moves file to new place. Original is gone.

Paste (Ctrl + V): Places the copied/cut file.

Rename (F2): Changing the name of a file.

Delete (Del): Sends file to Recycle Bin.

💡 Tip: Shift + Del deletes permanently!

6. Compression (ZIP)

Advanced Compressing files means reducing their size without losing data. It's like squeezing clothes into a suitcase.

Why? To save disk space and email files faster.

📦 Large Files → [ ZIP Tool ] → 🤏 Small .zip File

7. Backup & Restore

Backup: Making an extra copy of data on a Pen Drive or Cloud (Internet).

Restore: Bringing data back from the backup if the original is lost.

Reason: Protects against viruses, accidental deletion, or computer failure.

💻 PC Data ➡️ ☁️ Cloud / 💾 Pendrive
