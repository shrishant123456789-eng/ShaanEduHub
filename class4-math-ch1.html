1. The Indian Place Value System

In India, we group numbers into periods: Ones, Thousands, and Lakhs. This helps us read big numbers easily!

The Place Value Chart:

Lakhs Thousands Ones
TL L TTh Th H T O

Example Number: 5,42,109

Read as: Five Lakh Forty-Two Thousand One Hundred Nine.

💡 Memory Tip: Put a comma after 3 digits from the right, then every 2 digits! (e.g., 1,23,456)

Quick Check: Where do we put the first comma in 45678?

2. Place Value vs. Face Value

Every digit in a number has two values:

  • Face Value: The digit itself. It never changes.
  • Place Value: The value based on where it sits (Position).

In the number 2,853:

For digit 8:

👉 Face Value = 8

👉 Place Value = 8 × 100 = 800

3. Expanded Form & Short Form

Expanded form means breaking a number into parts based on place value.

Short form is putting it back together.

Number: 45,672

Expanded: 40,000 + 5,000 + 600 + 70 + 2

4. Successor and Predecessor

  • Successor: The number comes AFTER (+1).
  • Predecessor: The number comes BEFORE (-1).
[Image: Number Line 99 -> 100 -> 101]

Number: 500

Predecessor: 499 (500 - 1)

Successor: 501 (500 + 1)

5. Comparing Numbers

To compare big numbers:

  1. Count digits. More digits = Bigger Number.
  2. If digits are same, compare from Left to Right.

Ascending: Small to Big 📈

Descending: Big to Small 📉

6. International System (Advanced)

Used all over the world. The periods are Ones, Thousands, and Millions.

Millions Thousands Ones
HM TM M HTh TTh Th H T O
💡 Tip: Commas come after every 3 digits! (123,456,789)

1 Million = 10 Lakhs

7. Roman Numerals

Ancient Romans used letters for numbers. There is no Zero!

I = 1
V = 5
X = 10
L = 50
C = 100
D = 500
M = 1000

Rules:

  • Repeat to add (XXX = 30). Max 3 times.
  • Small after Big = Add (VI = 6).
  • Small before Big = Subtract (IV = 4).

8. Rounding Off Numbers

We round off to make numbers simpler.

  • 0, 1, 2, 3, 4: Round DOWN (Keep same).
  • 5, 6, 7, 8, 9: Round UP (+1 to neighbour).

Round 47 to nearest 10.

7 is strong (>5), so 4 becomes 5.

Answer: 50

Q1: What is the difference between the Place Value of 5 in 52,500?

Ans: First 5 is 50,000. Second 5 is 500.
Difference = 50,000 - 500 = 49,500.

⚡ Quick Revision

  • Face Value is the digit itself.
  • Place Value depends on position.
  • Indian System: 3, 2, 2 commas (1,23,45,678).
  • International System: 3, 3, 3 commas (12,345,678).
  • Roman Numerals have NO zero.
  • Smallest N digit number starts with 1 followed by zeros.
  • Largest N digit number contains only 9s.
