🧩 Software & Hardware

Class 2 • Chapter 7 • Computer Parts
🖥️ What is Hardware?

Hardware refers to the parts of a computer that we can See and Touch.
It is like the Body of the computer.
"Riya touched the keyboard to type. The keyboard is Hardware!" ⌨️

🛠️ Examples of Hardware

• Monitor 🖥️: Shows us pictures.
• CPU ⚙️: The brain inside the box.
• Keyboard ⌨️: Used for typing.
• Mouse 🖱️: Used to click.
• Printer 🖨️: Prints on paper.
• Speakers 🔊: Gives us sound.

🧠 What is Software?

Software is the set of instructions that tells the computer what to do.
We Cannot Touch software.
It is like the Brain/Idea inside the computer.
"Paint helps us draw pictures. Paint is Software!" 🎨

💿 Examples of Software

• Paint 🎨: Used for drawing.
• Games 🎮: Used for playing.
• Calculator 🔢: Used for sums.
• Windows 🪟: Helps computer start.
• Music Player 🎵: Plays songs.

⚖️ The Difference
Hardware 🖥️ Software 🧠
You can Touch it ✋ You cannot Touch it 🚫
It is the Body It is the Instruction
Ex: Mouse, CPU Ex: Paint, Games
📂 Types of Software

1. System Software: It helps the computer to run. Without it, the computer is just a box. Example: Operating System (Windows).

2. Application Software: It helps US do our work. Example: Paint for drawing, Notepad for typing.
