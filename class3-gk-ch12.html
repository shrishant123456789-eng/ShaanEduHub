🧩 Logical Reasoning

Definition: Logical reasoning is the ability to think clearly and solve problems using logic and patterns.

Explanation: Logical reasoning helps us understand patterns, complete sequences, and find the odd one out. It makes our brain sharper and helps us solve puzzles.

Types of Logical Reasoning Questions:

  • Number Series: Finding the next number in a pattern (Example: 2, 4, 6, 8, ___ → Answer: 10)
  • Odd One Out: Finding which item does not belong (Example: Cat, Dog, Cow, Chair → Answer: Chair, because it is not an animal)
  • Coding-Decoding: Finding patterns in codes (Example: If CAT = 3, then DOG = ?)

Example: Complete the series: 5, 10, 15, 20, ___. Answer is 25 because we add 5 each time.

💡 Memory Tip: Look for patterns! Numbers can go up, down, or repeat in a special way.

🔢 Number Series

Definition: A number series is a sequence of numbers that follow a specific pattern or rule.

Explanation: To solve number series, we need to find the rule or pattern. Common patterns include:

  • Adding the same number: 2, 5, 8, 11 (add 3 each time)
  • Multiplying by a number: 2, 4, 8, 16 (multiply by 2)
  • Subtracting a number: 50, 45, 40, 35 (subtract 5)

Example: Find the missing number: 10, 20, 30, ___, 50. Answer: 40 (adding 10 each time)

💡 Memory Tip: Check if numbers are increasing or decreasing, then find the difference!

🔍 Odd One Out

Definition: Odd one out means finding the item that is different from others in a group.

Explanation: We look at a group of items and find which one does not belong based on category, shape, or function.

Examples:

  • Apple, Banana, Mango, Carrot → Carrot is the odd one (it is a vegetable, others are fruits)
  • Chair, Table, Bed, Book → Book is the odd one (it is not furniture)
  • 2, 4, 6, 7, 8 → 7 is the odd one (it is not an even number)

Example: Find the odd one: Dog, Cat, Lion, Tree. Answer: Tree (it is not an animal)

💡 Memory Tip: Group things by category—animals, plants, objects, numbers!
❓ Quick Check: Which is odd: Red, Blue, Green, Circle?

🔤 Coding-Decoding

Definition: Coding-decoding is a way of writing words or numbers using a special code or pattern.

Explanation: In coding, we change letters or words into codes. In decoding, we find the original word from the code.

Examples:

  • If A=1, B=2, C=3, then CAT = 3+1+20 = 24
  • If DOG is written as EPH, then each letter moves one step forward

Example: If BOOK is coded as CPPL, what is DOOR? Answer: EPPS (each letter moves one step forward)

💡 Memory Tip: Check if letters move forward, backward, or follow a number pattern!
❓ Quick Check: If CAT = 3, how many letters in DOG?

🔺 Patterns and Shapes

Definition: Patterns are designs that repeat in a predictable way. Shape patterns use different shapes in a sequence.

Explanation: Patterns can be made with shapes, colors, or sizes. We need to find what comes next by observing the rule.

Examples:

  • Circle, Square, Circle, Square, ___ → Answer: Circle
  • Big triangle, Small triangle, Big triangle, ___ → Answer: Small triangle

🌍 Environment Awareness

Definition: Environment awareness means understanding how to protect our planet and keep it clean and healthy.

Explanation: We live on Earth, and it is our responsibility to take care of it. Pollution, waste, and cutting trees harm the environment.

Ways to Protect the Environment:

  • Reduce: Use less plastic and waste
  • Reuse: Use things again instead of throwing them away
  • Recycle: Turn old materials into new useful things

Example: Instead of using a plastic bag once, we can use a cloth bag many times.

💡 Memory Tip: Remember the 3 Rs: Reduce, Reuse, Recycle!

♻️ The 3 Rs: Reduce, Reuse, Recycle

Reduce: This means using fewer resources and creating less waste. Example: Turn off lights when not needed, use less water.

Reuse: This means using things more than once. Example: Use a water bottle multiple times instead of buying new ones.

Recycle: This means converting waste materials into new products. Example: Old newspapers can be recycled into new paper.

Example: Instead of throwing away a plastic bottle, we can refill it with water and use it again.

💡 Memory Tip: 3 Rs help keep Earth clean—Reduce waste, Reuse things, Recycle materials!

🏭 Pollution

Definition: Pollution is when harmful substances are added to the environment, making it dirty and unsafe.

Types of Pollution:

  • Air Pollution: Smoke from vehicles and factories makes the air dirty
  • Water Pollution: Throwing garbage in rivers and oceans
  • Noise Pollution: Loud sounds from vehicles, machines, and loudspeakers
  • Land Pollution: Throwing waste on the ground

Example: Smoke from cars causes air pollution, which can make us sick.

💡 Memory Tip: Keep air, water, and land clean to avoid pollution!

🛡️ Good Touch vs. Bad Touch

Definition: Good touch makes us feel safe and loved. Bad touch makes us feel uncomfortable or scared.

Explanation: It is important to know the difference between good and bad touch to stay safe.

Good Touch Examples:

  • A hug from parents or family
  • A handshake with a friend
  • A pat on the back from a teacher

Bad Touch Examples:

  • When someone touches private parts
  • When someone touches you in a way that makes you uncomfortable
  • When someone asks you to keep a touch secret

Important Rule: If anyone gives you a bad touch, say "NO" loudly and immediately tell a trusted adult like your parents or teacher.

💡 Memory Tip: If a touch makes you uncomfortable, it is a bad touch. Always tell a trusted adult!

📞 Emergency Numbers

Definition: Emergency numbers are special phone numbers we call when we need urgent help.

Important Emergency Numbers in India:

  • Police: 100
  • Fire Brigade: 101
  • Ambulance: 102
  • Women Helpline: 1091
  • Child Helpline: 1098
  • Emergency (All services): 112

Example: If there is a fire, call 101. If someone is sick or hurt, call 102 for an ambulance.

💡 Memory Tip: Police = 100, Fire = 101, Ambulance = 102. Remember these!
