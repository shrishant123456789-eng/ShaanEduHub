Class Notes 📝

1. Opening MS Paint

Definition: MS Paint is a simple program used to draw, colour, and edit pictures on a computer.

🏠 Indian Life Example: Just like you take out your drawing book from your school bag, we open Paint to start drawing on the computer screen!

Steps to Open:

  1. Click on the Start Button.
  2. Scroll down to Windows Accessories.
  3. Click on Paint.
[Image: Screenshot showing Start Menu -> Windows Accessories -> Paint]
🎨 Memory Tip: Remember "S-W-P" (Start - Windows - Paint).
2. Basic Drawing Tools

Where are they? In the Home Tab inside the Tools Group.

  • ✏️ Pencil Tool: Used for free-hand drawing (like writing your name).
  • 🖌️ Brushes: Used to draw with different textures (crayon, marker, oil paint, watercolor).
  • ⬜ Shapes: Ready-made shapes like Rectangle, Oval, Triangle, and Stars.
  • 🪣 Fill with Color: Used to fill a closed shape with selected color.
🏫 School Task: Use the Rectangle tool to draw your school blackboard and Fill tool to color it black!
[Image: Icons of Pencil, Brush, Bucket, and Shapes group]
3. Colour Selection

To make our drawing beautiful, we need colors!

  • Color 1 (Foreground Color): Used for Pencil and Brushes (Outline color).
  • Color 2 (Background Color): Used for the Eraser and shape fills.

How to choose? Click on Color 1, then click any color box in the Colors Group.

💡 Tip: Left click uses Color 1. Right click uses Color 2!
4. Copying and Moving

Why draw the same flower 10 times? Just draw one and COPY it!

Steps to Copy:

  1. Use Select Tool to draw a box around the object.
  2. Click Copy (or press Ctrl + C).
  3. Click Paste (or press Ctrl + V).

Moving (Cut & Paste): Removes the object from one place and puts it in another.

🌸 Rangoli Time: Draw one Rangoli pattern, Copy it, and Paste it 4 times to complete the design quickly!
5. Eraser Tool Practice

Made a mistake? Don't worry!

  • Select the Eraser Tool (Pink rubber icon).
  • Click and drag over the mistake to remove it.
📏 Pro Tip: Press Ctrl + Plus(+) to make the eraser bigger!
6. Drawing a Creative Picture

Let's combine tools to make a Scenery.

  1. Use Line Tool for mountains.
  2. Use Oval Tool for the Sun.
  3. Use Pencil for birds.
  4. Use Fill with Color to color the sky blue and grass green.
🇮🇳 Project: Drawing the Indian Flag using Rectangle tool (for bands) and Oval/Line tools (for Ashoka Chakra).
[Image: Simple scenery drawing created in Paint]
7. Saving Artwork

If you close the computer without saving, your drawing will vanish!

Steps:

  1. Click on the File tab (Blue button).
  2. Click Save.
  3. Type a name (e.g., "MyDiwaliCard").
  4. Click Save Button.
💾 Shortcut: Press Ctrl + S to save quickly.
8. Understanding Icons

Match the tool to the work:

  • 🔍 Magnifier: Zooms in to see details (like a detective!).
  • 🅰️ Text Tool: Used to type your name on the drawing.
  • 🧪 Color Picker: Picks a color from the drawing to use again.
