🎥 Module 1: Basic Foundations

1. The Timeline & The Cut BASIC

Definition: The timeline is the chronological workspace where video clips, audio, and graphics are arranged. A 'cut' is the immediate transition from one shot to another.

DIAGRAM: NLE Timeline Structure (V1, V2, A1, A2 Tracks)
Workflow Logic

Always maintain a "Pancake Timeline" or organized track structure. V1 is main footage, V2 is B-roll, V3 is graphics/text.

🇮🇳 Indian Context: A wedding editor in Surat arranges the 'Pheras' on V1 (Main Cam) and 'Relatives Reactions' on V2 to cut away when the footage shakes.
Tools: CapCut (Mobile split), Premiere Pro (Razor Tool - C), Filmora (Scissors).
2. Aspect Ratios & Standards BASIC

Technical: Understanding canvas dimensions is crucial before import. 16:9 (Horizontal), 9:16 (Vertical), 1:1 (Square), 4:5 (Insta Portrait).

🎬 Industry Standard: YouTube uses 1920x1080 (16:9). Reels/Shorts use 1080x1920 (9:16). Bollywood films often use 2.39:1 (Anamorphic).

Memory Tip: "Shorts stand tall (9:16), TV sleeps wide (16:9)."

3. Formats & Codecs BASIC

Definition: Container (MP4, MOV) holds the data. Codec (H.264, ProRes) compresses it.

Critical Distinction

H.264/H.265: Highly compressed, good for delivery (YouTube/WhatsApp). Hard for computer to edit.
ProRes/DNxHR: Less compressed, huge file size, smooth to edit.

🇮🇳 Daily Life: Sending a video on WhatsApp compresses it to H.264 low bitrate, losing quality ("pixelated").

🎥 Module 2: Medium Workflows

4. Color Correction Basics MEDIUM

Definition: Fixing the image to look natural. Adjusting Exposure, White Balance, and Contrast.

The Lumetri/Color Page Workflow

1. Fix Exposure (Whites/Blacks).
2. Fix White Balance (Temperature/Tint).
3. Fix Saturation.

Tools: DaVinci Resolve (Primary Wheels), Premiere Pro (Lumetri Basic Correction).
5. Audio Sync & Sound Design MEDIUM

Concept: Matching external high-quality audio with camera reference audio.

🎬 Workflow: Use "Clap Sync" or Waveform matching. In Premiere: Select both clips -> Right Click -> "Synchronize".
🇮🇳 Indian Context: Tech YouTubers record voice on a separate mic (Rode) and video on Sony camera. They must sync the clap at the start.
6. Collaborative File Workflows MEDIUM

Definition: Systems enabling multiple editors to work on the same project remotely.

Key Concept: 'Project Locking' prevents two people from saving over each other.

Tools: Frame.io (Review), Dropbox Replay, Adobe Team Projects.

🎥 Module 3: Advanced Techniques

7. Proxy Workflows ADVANCED

Problem: 4K raw footage lags on laptops.

Solution (Proxy): Creating temporary low-res copies for editing. The software swaps back to high-res for final export.

DIAGRAM: High Res File -> Media Encoder -> Proxy File
🇮🇳 Scenario: A travel vlogger in Ladakh shooting 4K Log on a drone uses Proxies to edit on a MacBook Air in a hotel room.
8. Motion Graphics Sequencing ADVANCED

Definition: Integration of animated text, lower thirds, and vector shapes via Dynamic Link.

Workflow: Design in After Effects -> Save -> Drag .aep composition into Premiere timeline. No rendering needed until final export.

9. Multicam Editing ADVANCED

Technique: Editing footage from multiple cameras shooting the same event simultaneously.

Process: Sync all angles -> Create Multicam Sequence -> Use keyboard keys (1, 2, 3) to switch angles live during playback.

🎬 Use Case: Comedy Specials (Netflix), Podcast Shoots, Reality TV.

🎥 Module 4: Expert Systems

10. Cinematic Color Grading EXPERT

Different from Correction: Grading is creative styling. Creating a "Look" or "Mood".

Terms: LUT (Look Up Table), Teal & Orange (Color Contrast), Skin Tone Line (Vectorscope).

Power Tool: DaVinci Resolve Nodes (Serial, Parallel, Layer Mixer).
11. Brand Identity Systems EXPERT

Definition: Creating MOGRTs (Motion Graphics Templates) that lock fonts, colors, and logo placement for junior editors.

🎬 Corporate: Zomato or Swiggy ads maintain exact brand red/orange colors across thousands of video assets using rigid MOGRTs.
