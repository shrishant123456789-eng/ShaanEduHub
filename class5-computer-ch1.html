📘 Chapter Notes

1. Block Diagram of Computer

A computer is not just one box. It is a system of parts working together.

[ INPUT UNIT ] ➡️ [ CPU (Process) ] ➡️ [ OUTPUT UNIT ] ⬇️ [ MEMORY UNIT ]

Basic: It takes data, works on it, and gives results.

Advanced: The CPU acts as the brain, controlling data flow between input, memory, and output devices via the system bus.

🏠 Life Example: Making Mango Shake.
Mango + Milk (Input) ➡️ Mixer (Process) ➡️ Shake (Output).
2. IPO Cycle (Input-Process-Output)

Every computer follows this cycle strictly.

  • Input: Raw facts/data entered (Keyboard, Mouse).
  • Process: Working on data (CPU).
  • Output: Meaningful result displayed (Monitor, Printer).
💡 Tip: Remember "IPO" - Like a factory line!
3. The CPU (Central Processing Unit)

The brain of the computer. It has three main parts:

  1. ALU (Arithmetic Logic Unit): Does math (+, -, *, /) and logic (<, >, =).
  2. CU (Control Unit): Traffic policeman. Tells parts what to do.
  3. MU (Memory Unit): Stores data temporarily during processing.
4. Fetch – Decode – Execute Cycle

How the CPU actually runs a program:

  • Fetch: CPU gets instruction from memory.
  • Decode: CU figures out what the instruction means.
  • Execute: ALU performs the action.
🐕 Example: Dog Fetching Ball.
See ball (Fetch) ➡️ Understand "Bring it" (Decode) ➡️ Run & get it (Execute).
5. Data vs Information

They are NOT the same!

  • Data: Raw facts. No meaning alone. (e.g., "5", "Red")
  • Information: Processed data. Has meaning. (e.g., "5 Red Apples")
6. Memory Units

Computer understands only 0 and 1 (Binary).

  • Bit: Smallest unit (0 or 1).
  • Nibble: 4 Bits.
  • Byte: 8 Bits (1 Character).
  • KB (Kilobyte): 1024 Bytes.
  • MB (Megabyte): 1024 KB.
  • GB (Gigabyte): 1024 MB.
  • TB (Terabyte): 1024 GB.
🧠 Tip: "Big King Midas Got Toffees" (Byte, KB, MB, GB, TB).
7. Processing Speed

How fast a CPU thinks.

Measured in Hertz (Hz).

  • Old computers: MHz (Megahertz - Million cycles/sec).
  • Modern computers: GHz (Gigahertz - Billion cycles/sec).
